# Compiler identity and execution evidence

The private core 0.12.36 candidate exposes two read-only operation routes. These
require neither write, execution nor dependency-network permission.

`compiler_identity` accepts an empty request. It returns
`ingestron.compiler-identity/v1`, the installed core version and an integrity-checked
SHA-256 compiler digest. It does not read or write a project. The
`execution_features` route declares `compilerIdentity: true` and
`executionEvidence: true`, alongside runtime preparation identity support.

`execution_evidence` validates a managed build, its unchanged project inputs,
locked provider and flow selection. Supply `from` and `flow` for a selected build,
or the original receipt `id` and its exact `flow` and optional `profile`. It
returns `ingestron.execution-evidence/v1`, current compiler identity, build plan
digest, original build compiler identity, `build.current`, environment, profile,
flows and provider reference/commit. An original selection includes only its ID,
action and status. This route neither runs the provider adapter nor reads source
rows. It validates the installed provider's declared execution resources.

```javascript
const evidence = await executeAsync(
  { root: projectDirectory, environment: "dev" },
  "execution_evidence",
  { from: "build/studio/dev/orders", flow: "orders" },
);
```

Fresh execution and runtime preparation require a build generated by the current
installed compiler. An earlier version or digest returns `STALE` before a new
receipt or provider execution is created. Prepare, inspect and approve a current
build before running it.

Original interrupted operations retain their immutable build and original
fingerprint. Their existing retry or acknowledgement routes remain available
after a compiler upgrade when that build, inputs, package locks and provider
still match. A successful original acknowledgement is historical evidence; it
does not prove execution with the new compiler. Missing or malformed compiler
metadata cannot establish current build evidence.

The shared Studio revision includes the installed compiler version and digest.
Recovered jobs additionally retain whether their original compiler is current.
Historical recovery cannot complete a current flow test or supply current output
or quality results. Older CLIs fall back to their version for revision identity;
they do not advertise the stronger compiler evidence route.

Qualification uses genuine builds from immutable core 0.12.35 and 0.12.36 archives
with the same CLI 0.17.16 archive. An actual paused provider finaliser and terminated
adapter exercise original recovery; a new shared-host preparation, reviewed
approval and synthetic CSV run verify fresh execution. SDK-prepared runtime
adoption, finaliser death, all connector/platform variants and browser interaction
remain separate incomplete work.
